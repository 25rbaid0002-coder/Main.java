# Ride-Hailing App Simulator (Ola / Uber style)

## About
The **Ride-Hailing App Simulator** is a Java application designed to simulate how a ride-hailing platform matches riders with drivers and calculates dynamic fares.

## Features & Team Modules
* **Member 1:** Rider & Driver Registration
* **Member 2:** Ride Request & Nearest Driver Matching
* **Member 3:** Fare Calculation & Surge Pricing
* **Member 4:** Concurrent Ride Requests (Multithreading)
* **Member 5:** Ride History & File Storage

## Java Concepts Used
* Abstract classes, interfaces, polymorphism, inheritance
* Data structures (`ArrayList`, `HashMap`)
* Multithreading & synchronization
